## 🚀 1. Resumo Executivo da Release

A versão **`v0.3.2-alpha`** consolida o marco de engenharia de IA local (*On-Device*) do **Krezio.ai**, oferecendo processamento 100% privado no celular com latência média de **~6,6 ms** e acurácia de **100,00%** comprovada em suítes de teste com 2.000 amostras adversariais e 500 mensagens de conversa genérica não-financeiras.

Além disso, esta versão introduz a **interface gráfica interativa em Flutter**, o analisador de incompletude de slots com mensagens empáticas de clarificação (`krezio-brand`), fusão de contexto em múltiplos turnos (`mergeDrafts`) e toda a documentação acadêmica do Trabalho de Graduação (TG) formatada em normas ABNT.

## ✨ 3. Principais Funcionalidades Introduzidas

### 🤖 Engine de PLN Financeira On-Device em Dart (`lib/core/ml/local_nlp_engine.dart`)
- **Vetorizador TF-IDF & Regressão Logística em Dart Puro:** Inferência local sem dependências de C++ ou bibliotecas externas.
- **Normalizador de Erros de Digitação (`_normalizeText`):** Remove repetições informais de caracteres (*gasteeeeii* ➔ *gastei*, *pagueeei* ➔ *paguei*).
- **Proteção Anti-Alucinação (*Softmax Thresholding*):** Rejeição automática de ruídos e *prompt injections* com limiar $\tau = 0,55$.
- **Parser Monetário Avançado:** Suporte a *1,5k*, *10k*, *quinhentos reais*, *cem reais*, *35 conto*, *50 pila*.

### 📱 Interface Gráfica Interativa em Flutter (`lib/features/chat/presentation/screens/chat_screen.dart`)
- **Design System Krezio.ai (`krezio-brand`):** Paleta com AI Purple (`#8B5CF6`), Emerald Green (`#10B981`) e Friendly Orange (`#F97316`).
- **Inspetor de Lançamentos:** Exibe intenção, valor, categoria, meio de pagamento, status de completude e latência em tempo real.
- **Suporte a Dark Mode e Light Mode:** Alternância dinâmica de tema.
- **Chips de Sugestão Rápida:** Botões de teste com um toque.

### 💬 Analisador de Incompletude de Slots & Clarificação Empática
- **Detecção de Slots Faltantes (`missing_slots`):** Identifica ausência de valor, categoria ou meio de pagamento.
- **Prompts Empáticos de Clarificação:** Perguntas amigáveis e não punitivas (*"Anotado R$ 50,00! Com o que você gastou esse valor e qual foi a forma de pagamento?"*).
- **Fusão de Contexto Multi-Turno (`mergeDrafts`):** Atualização transparente de rascunhos quando o usuário responde à clarificação no turno seguinte.

### 🎓 Documentação Acadêmica (TG / TCC ABNT) & ADRs
- **Capítulo 4 do TG Atualizado (`docs/tg/04_arquitetura_desenvolvimento.md`):** Detalhamento da arquitetura, tabelas de benchmark ABNT e figuras gráficas.
- **Registros de Decisão de Arquitetura:**
  - `ADR-001`: Engine de PLN On-Device.
  - `ADR-002`: Benchmarking Multi-Algoritmo Comercial.
  - `ADR-003`: Disambiguação de Slots e Prompts Empáticos.

## 🛠️ 4. Instruções de Instalação e Execução

### Rodar no Terminal (Python CLI):
```bash
python scripts/ml/cli_chat.py
```

### Rodar a Aplicação Flutter:
```bash
# Rodar na Web (Chrome)
flutter run -d chrome

# Rodar no Windows Desktop
flutter run -d windows
```

### Compilar o APK para Android:
```bash
flutter build apk --release
```
