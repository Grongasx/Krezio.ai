# RESUMO

O presente trabalho apresenta o desenvolvimento do **Krezio.ai**, uma aplicação mobile focada em gestão financeira pessoal com assistente virtual preditivo. A pesquisa aborda os desafios do controle financeiro pessoal, propondo uma interface minimalista e não alarmista que utiliza psicologia das cores (substituindo o vermelho sangue por laranja amigável para alertas de saída) e inteligência artificial para fornecer orientações empáticas baseadas em dados. A metodologia adotada inclui o desenvolvimento experimental com o framework Flutter e integração com modelos de linguagem. Os resultados demonstram maior engajamento dos usuários e redução do estresse associado ao acompanhamento financeiro.

**Palavras-chave:** Gestão Financeira Pessoal. Inteligência Artificial. Flutter. UX Writing. Psicologia das Cores.

# ABSTRACT

This work presents the development of **Krezio.ai**, a mobile application focused on personal financial management powered by a predictive virtual assistant. The research addresses the challenges of personal financial control, proposing a minimalist, non-alarmist interface that uses color psychology (replacing blood red with friendly orange for expense alerts) and artificial intelligence to deliver empathetic, data-driven insights. The methodology includes experimental development using the Flutter framework and integration with language models. Results demonstrate higher user engagement and reduced stress associated with financial tracking.

**Keywords:** Personal Finance Management. Artificial Intelligence. Flutter. UX Writing. Color Psychology.
